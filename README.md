This app is the Next Generation rewrite of CameraAlign that addresses some issues and adds a new feature.  The NG version works on newer versions of Android.  The NG version also adds a "Stop Motion" feature.  When the "Stop motion" button is pressed it will replace the background photo with a fresh photo taken from the camera.  The app also allows the option to save or discard the freshly taken photo.  

This app is 100% vibe coded with Gemini 3.6 Flash and Gemini 3.5 Flash Lite.  

This app has no ads or in-app purchases and collects no data.
